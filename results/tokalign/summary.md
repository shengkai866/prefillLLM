# 跨分词器的 token 对齐（Cache-to-Cache 方法）

大模型保留自己的 token；小模型的每个位置是对应大 token 的字符串用小模型分词器重新编码后最长的那个 token。“精确”= 小词表里有同样字节串的 token；“保留字节”= 小模型序列保留的大 token 字节占比；“小模型自然长度”= 同一文本用小模型分词器直接编码的长度（相对大模型序列）。

## Qwen3-1.7B ← Llama-3.1-8B-Instruct 的 prompt

词表映射：{'n_large': 128256, 'n_small': 151669, 'exact': 109566, 'role': 7, 'reencoded_1to1': 0, 'reencoded_longest': 18683, 'fallback': 0}

| 池 | 序列数 | 精确 token 占比 | 保留字节占比 | 小模型自然长度 / 大模型长度 |
|---|---|---|---|---|
| qa_eval | 50 | 0.978 | 0.985 | 1.043 |
| code_eval | 50 | 0.986 | 0.993 | 1.022 |

多 token 取最长的例子（大 token → 小 token）：`'00'`→`'0'`；`'220'`→`'2'`；`'410'`→`'4'`；`'860'`→`'8'`；`'705'`→`'7'`；`'583'`→`'5'`；`'989'`→`'9'`；`' औ'`→`' �'`；`'iến'`→`'ến'`；`'λε'`→`'λ'`；`'\u200cها'`→`'ها'`；`' durum'`→`' dur'`；`'елов'`→`'ел'`
